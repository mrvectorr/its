# Aufgabe 3.3 Benutzerauthentifizierung
In der nachfolgenden Tabelle sind in den Spalten 2-5 die drei gebräuchlichsten Authentifizierungsmethoden aufgeführt. Geben sie zu jeder Zeile jeweils mindestens eine Antwort.

| Kriterium | Geheimes Wissen | Persönlicher Besitz | Biometrie |
|---|---|---|---|
| **Möglichkeiten des Verlustes** | - Vergessen des Passworts / der PIN<br>- Phishing oder Social Engineering<br>- Datenbankleaks (Passwortdiebstahl)<br>- Shoulder Surfing (Beobachten der Eingabe)<br><br>**Risiko:** Hoch | - Physischer Verlust (Token, Chipkarte, Smartphone)<br>- Diebstahl des Geräts<br>- Defekt oder Zerstörung des Tokens<br>- Klonen/Kopieren bei schwachen Karten<br><br>**Risiko:** Mittel | - Kein direkter Verlust möglich<br>- Verletzungen können biometrische Merkmale verändern<br>- Alterung beeinflusst biometrische Daten<br><br>**Risiko:** Gering |
| **Übertragung an andere Personen** | - Passwort / PIN kann leicht weitergegeben werden<br>- Weitergabe mündlich, schriftlich oder digital möglich<br>- Missbrauch schwer nachvollziehbar<br><br>**Übertragbarkeit:** Sehr einfach | - Physische Übergabe des Tokens oder der Karte notwendig<br>- Weitergabe gezielt möglich, aber aufwendiger<br>- Verleihen von Smartcards oder Hardware-Token möglich<br><br>**Übertragbarkeit:** Eingeschränkt | - Grundsätzlich nicht übertragbar<br>- Spoofing-Angriffe möglich (z. B. Silikonfingerabdruck)<br>- Liveness Detection reduziert das Risiko<br><br>**Übertragbarkeit:** Kaum möglich |
| **Ersatz des Authentifizierungsobjekts** | - Passwort-Reset per E-Mail oder Admin möglich<br>- PIN kann geändert werden<br>- Neues Passwort sofort nutzbar<br><br>**Aufwand:** Sehr gering | - Neue Chipkarte oder neuer Token erforderlich<br>- Zeit- und Kostenaufwand für Neuausstellung<br>- Übergangszeit ohne Authentifizierungsmittel möglich<br><br>**Aufwand:** Hoch | - Biometrische Merkmale sind nicht austauschbar<br>- Bei Datenleaks kein vollständiger Ersatz möglich<br>- Alternative biometrische Verfahren als Ausweichlösung<br><br>**Aufwand:** Nicht ersetzbar |
| **Beispiele** | - Passwort (Systemlogin, Online-Banking)<br>- PIN (EC-Karte, Smartphone)<br>- TAN (Transaktionsnummer)<br>- Sicherheitsfragen | - Chipkarte / Smartcard<br>- Hardware-Token (z. B. RSA SecurID)<br>- Smartphone mit Authenticator-App<br>- USB-Sicherheitsschlüssel (z. B. YubiKey) | - Fingerabdruckscanner<br>- Gesichtserkennung (Face ID)<br>- Iris- / Retina-Scan<br>- Stimmerkennung<br>- Handvenenscanner |

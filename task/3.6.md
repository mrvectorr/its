# 3.6 Biometrische Benutzerauthentifizierung

<!-- new_line -->

## Fragestellung:

<!-- new_line -->

Kann die Handschrift in der Biometrie als statische und als dynamische Modalität angesehen werden? Begründen Sie Ihre Antwort.

**Kurze Antwort**: Beides! Aber warum?

---

## Was wird Betrachtet?

<!-- new_line -->

| Statisch                           | Dynamisch                             |
| ---------------------------------- | ------------------------------------- |
| Betrachtet das fertige Schriftbild | Betrachtet den Schreibvorgang         |
| Fokus auf "Was wurde geschrieben?" | Fokus auf "Wie wurde es geschrieben?" |
| Vergleich eines Bildes             | Analyse von Bewegungsdaten            |

<!-- new_line -->

Es wird das Schriftbild an sich mit einer Referenz verglichen. Es wird meist die eindeutige Unterschrift des Nutzers verwendet, um diesen zu Identifizieren.

---

## Berücksichtigte Merkmale: 

<!-- new_line -->

| Statisch         | Dynamisch               |
| ---------------- | ----------------------- |
| Buchstabenformen | Schreibgeschwindigkeit  |
| Größe            | Druck                   |
| Neigungswinkel   | Beschleunigung          |
| Abstände         | Reihenfolge der Striche |
| Linienführung    | Pausen                  |
| Proportionen     | Bewegungsdynamik        |

<!-- new_line -->

**Kurz**: Als statische Modalität wird das Endergebnis betrachtet, als dynamische Modalität der Entstehungsprozess.

---

## Technische Voraussetzungen: 

<!-- new_line -->

| Statisch                             | Dynamisch                                      |
| ------------------------------------ | ---------------------------------------------- |
| Scanner / Kamera                     | Spezialhardware z.B. Grafiktablett             |
| Papierdokument                       | Tablet, Stylus oder Sensoren                   |
| Einfache Datenerfassung (Kamera-App) | Aufwendige Datenerfassung (spezielle Software) |

---

## Risiken:

<!-- new_line -->

| Statisch                            | Dynamisch                                        |
| ----------------------------------- | ------------------------------------------------ |
| Leicht kopierbar                    | Replay-Angriffe möglich                          |
| Bild kann bearbeitet werden         | Bewegungsdaten können abgefangen werden          |
| einfaches erstellen von Fälschungen | Höherer Technischer Aufwand (mehr Fehlerquellen) |

<!-- new_line -->

**Vorteile dynamisch**: 

- Verhalten beim Schreiben schwer imitierbar
- Es werden mehr biologische Informationen verarbeitet

---

## Datenschutz

<!-- new_line -->

Dynamische Verfahren erfassen deutlich mehr sensible Daten über Verhalten und Motorik. 
Diese können Auskunft über den Nutzer geben (Parkinson, Alter, allgemeine körperliche Verfassung etc.).

Verwendung von globalen Semantiken schützen die Identität des Nutzers, da keine individuelle Unterschrift genutzt wird.
Allerdings sinkt hierbei die Sicherheit durch eine höhere FAR.

---

## Fazit:

<!-- new_line -->

Die Handschrift kann sowohl als statische, als auch dynamische Modalität verwendet werden.
Während bei statischen Verfahren das fertige Schriftbild betrachtet wird, ist bei dynamischen Verfahren der individuelle Schreibprozess

<!-- new_line -->

**Warum die Handschrift als dynamische Modalität besser geeignet ist**
Das Bild einer Unterschrift kann jederzeit kopiert werden. 
Den Schreibstil, -druck und -Geschwindigkeit nachzuahmen ist deutlich schwieriger.
Hierbei nimmt die Schwierigkeit mit der Komplexität der Schrift zu.
